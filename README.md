# 📍 GPS-Based Attendance System

A modern web application for managing student attendance using real-time GPS location tracking.

<img width="578" height="938" alt="image" src="https://github.com/user-attachments/assets/0b7b98c5-ddd3-4956-a967-6c3b80ebe77f" />


## 🌟 Features

- ✅ Real-time GPS location validation
- ✅ Device fingerprinting for anti-cheating
- ✅ Radius-based attendance verification (500m)
- ✅ Duplicate prevention system
- ✅ Admin dashboard with analytics
- ✅ Data export (CSV/Excel)
- ✅ Mobile-responsive design
- ✅ Secure authentication

## 🚀 Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3
- **Backend:** Supabase (PostgreSQL)
- **APIs:** HTML5 Geolocation, FingerprintJS2
- **Deployment:** GitHub Pages
- **Security:** Device fingerprinting, IP tracking, SHA-256 hashing

## 🎯 Use Case

Currently used by Electrical Engineering Faculty at Riau Kepulauan University (UNRIKA) 
for laboratory attendance management across 8 practical groups.
